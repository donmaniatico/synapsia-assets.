# 🎨 Synapsia - Activos Gráficos y Avatares 2D

Repositorio oficial de recursos gráficos, avatares vectoriales y elementos modulares de la aplicación **Synapsia**.

## 📁 Estructura del Repositorio
* `avatars_2d/templates/` -> Avatares base de cuerpo entero (incluyendo `peep-standing-1.svg` y `peep-standing-8.png`).
* `avatars_2d/atoms/` -> Capas independientes de ropa, caras, cabezas y accesorios para el sistema modular.
